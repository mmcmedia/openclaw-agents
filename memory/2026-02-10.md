## Usage Blowout Investigation & Fix
McKinzie noticed a full week of API usage burned in ~1 day. Had to switch API keys.

### Root Causes Found:
1. **Compaction was `safeguard` mode** — only compacts at context LIMIT (1M tokens), not proactively. Sessions ballooned to 1M tokens (dev-tech-ai group, team-management-agent group both maxed out).
2. **All isolated cron jobs (agentTurn) ran on Opus** — no model override specified, so they inherited the default Opus model. 9 cron jobs × daily/weekly = massive spend.
3. **n8n failure investigator** ran every 30 minutes on Opus — killed it.
4. **Group chats** with `requireMention: false` meant every message triggered Opus.

### Fixes Applied:
- Compaction: `safeguard` → `default` (proactive compaction)
- Context window: 1M → 250K tokens
- 9 isolated cron jobs downgraded from Opus → Haiku (daily-site-health, sage-daily-scan, scout-daily-monitor, maria-morning-dispatch, milo-weekly-research, weekly-self-optimization, weekly-team-report, weekly-seo-scan, weekly-analytics-opportunity-scan)
