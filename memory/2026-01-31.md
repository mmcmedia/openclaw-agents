## GenSpark AI Drive Download Workflow - DISCOVERED

McKinzie asked me to figure out how to download the 21 generated clips from GenSpark AI Drive.

**What I tried first (wrong approaches):**
1. Research if GenSpark/PixVerse has an API → Found PixVerse has one at platform.pixverse.ai, but McKinzie already paid for GenSpark credits
2. Manual browser navigation → Works but tedious (click file → Download → repeat 21 times)
3. Looking for bulk download button → "Download For Me" is for importing TO AI Drive, not downloading FROM it

**What worked (THE SOLUTION):**
ASK GENSPARK DIRECTLY! Just type in the chat:
```
How can I bulk download all files from a folder in AI Drive? 
I have 21 files in a folder called 'Secondhand Polaroid Music Video Clips' 
and I want to download them all at once instead of one by one.
```

GenSpark will:
1. List folder contents
2. Try to compress to ZIP (may not always work)
3. Generate **direct download URLs** with auth tokens for each file
4. Provide instructions for using download manager (JDownloader, Free Download Manager, etc.)

**Download URL format:**
```
https://www.genspark.ai/api/files/s/{FILE_ID}?token={AUTH_TOKEN}
```

**Key insight:** GenSpark can help you with its own platform! Don't struggle with manual navigation.
