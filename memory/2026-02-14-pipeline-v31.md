### 🎯 Pipeline Architecture (4 Stages)

| Stage | Model | Time | Cost | Purpose |
|-------|-------|------|------|---------|
| 1. Technical | Self-healer | ~1s | $0.05 | Auto-fix pronouns, duplicates, foreign words |
| 2. Editorial | GPT-5.2 | ~1 min | $0.50 | 12KB professional critique, catches structural issues |
| 3. AI Revision | GPT-5-mini | ~1-2 min | $0.50 | Targeted section fixes with 3-attempt retry |
| 4. Learning | - | <1s | - | Log patterns to learning DB |

**Total:** ~2.5 min, ~$1.05 per story

### 🔧 Critical Technical Decisions

**Model Selection:**
- **GPT-5.2** for editorial review only (reasoning_effort: 'low')
- **GPT-5-mini** for all revisions (reasoning_effort: 'low' — prevents token-eating reasoning loops)

**Retry Logic:**
- 3 attempts per fix with escalating strategies
- Attempt 1: Light fix (identify issues)
- Attempt 2: Restructure (more aggressive)
- Attempt 3: Major rewrite (radical changes)

**Targeted vs Full Rewrite:**
- Fix specific sections (Chapter 2, magic rules, ending) instead of full story
- 56 sec per section vs 25+ min for full rewrite
- Validation after each fix

### 💡 Key Learning

**Explicit reasoning_effort: 'low' is CRITICAL:**
- Without it: GPT-5.2/mini consume 1500-2000 tokens on reasoning, return empty
- With it: Normal token usage, actual content returned
- Must set on ALL calls, even GPT-5-mini

**Targeted revision works:**
- Section-by-section fixes are 26x faster than full rewrites
- Retry loop catches failures and escalates
- Validation ensures quality before marking complete
