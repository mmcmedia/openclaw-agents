### The Multi-Chapter Duplication Bug Discovered

**Problem:** Full 3-chapter story scored 5/10 because of "multiple overlapping drafts pasted together"

**Root Cause:** Chapter 1 itself had duplicate scenes saved to database
- Scene 1.2 appeared twice with different content
- Scene 1.3 appeared twice with different content
- Assembly script concatenated ALL saved scenes (including variants)

**Why This Happened:**
- Pipeline generated multiple variants of scenes during testing
- All variants were saved to DB (no deduplication)
- Assembly retrieved ALL scenes and concatenated them

### The Real Fix (Not Cross-Chapter Continuity)

The issue is NOT cross-chapter continuity - it's **intra-chapter deduplication**.

**Solutions Identified:**

1. **Storage Layer Fix (Long-term)**
   - Add UNIQUE constraint on (story_id, chapter_number, scene_number)
   - Use upsert (not insert) for scenes
   - Prevents duplicate scene storage

2. **YouBooks/MidReal Approach (Best Practice)**
   - Generate FULL 3-chapter outline FIRST (all 12 scenes at once)
   - Validate continuity at outline stage (before any prose)
   - Then generate prose scene-by-scene with forward-feeding summaries
   - This prevents duplication because outline is planned holistically

3. **Manual Cleanup (Immediate)**
   - Edit file to remove duplicate scenes
   - Keep best version of each scene
   - Fastest path to clean story
