## Key Lessons Learned

1. **GA4 Property ID vs Account ID** - Always use property ID (e.g., 361561956), not account ID (e.g., 80120206). Check with `analyticsadmin.accountSummaries.list()` to see correct IDs.

2. **Nano Banana image downloads** - The temp URLs work but need User-Agent header. Use curl with `-H "User-Agent: Mozilla/5.0"` or they return 403.

3. **OAuth token refresh** - googleapis library auto-refreshes IF you pass expiry_date in setCredentials(). Without it, uses expired token and fails silently.
