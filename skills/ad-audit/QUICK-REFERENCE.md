## The 3x Kill Rule

**Any ad group with CPA >3x target = PAUSE immediately**

Examples:
- Target CPA $20, actual $70 → KILL
- Target CPA $15, actual $50 → KILL
- Target CPA $30, actual $85 → KILL

Prevents wasted spend on losers.

---

## Creative Fatigue Signals

| Signal | Warning | Action |
|--------|---------|--------|
| CTR drop >20% over 14 days | Fatigue confirmed | Refresh creative |
| Frequency >5.0 (7-day) | Audience exhausted | Pause, new audience |
| No new creative in 60 days | Stale content | Launch new assets |
| Frequency >3.0 | Watch closely | Monitor daily |

2. ✗ CPA >3x target (3x Kill Rule)
3. ✗ Budget <5x CPA per ad set
4. ✗ Edits during learning phase
