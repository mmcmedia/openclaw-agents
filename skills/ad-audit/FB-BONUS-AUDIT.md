## Quick Audit Questions

Ask yourself (or have Jan/Deanne check):

1. **When did we last post a new hair graphic design?**
   - If >30 days ago → M-CR1 warning
   
2. **Are we rotating creative or posting the same designs repeatedly?**
   - If repeating >3x → Fatigue risk
   
3. **Do we have UTM parameters on all links?**
   - Check URLs for `utm_source=facebook&utm_medium=social`
   - If missing → M39 fail (no GA4 attribution)

4. **What's our average frequency per post?**
   - In Meta Business Suite → Insights → Audience
   - If >5 → Audience exhausted (M-CR2 fail)

5. **Are we excluding past engagers from new campaigns?**
   - If not → Audience overlap, wasted spend

## Content Rotation Strategy

To avoid creative fatigue (M28):

**Week 1-2:** Post Set A (3-4 graphics)
**Week 3-4:** Post Set B (3-4 new graphics)  
**Week 5-6:** Post Set C (3-4 new graphics)
**Week 7+:** Back to Set A (now refreshed)

This keeps frequency low and freshness high.
